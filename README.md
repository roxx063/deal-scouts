# Deal Scouts mobile scripts

Six browser bookmarklet tools for Zepto, Blinkit, Amazon Now, BigBasket, Flipkart Minutes and JioMart Quick.

Run only on the matching shopping website with your delivery address selected. Scripts use that website session to discover products and prices. They do not place orders or change the cart. Results open in a separate tab. Page caps and failed requests are reported; results do not guarantee complete catalogue coverage or checkout stock.

Mobile launchers pin an immutable release and SHA-384 script integrity. A launcher first tries an external script. Where the website permits fetch and evaluation, it can use that permitted path; restrictive site policies may prevent launch.

Upstream Zepto, Blinkit, Amazon Now and Flipkart Minutes libraries by jairaj26 are distributed under the accompanying MIT notices. Shared UI and BigBasket/JioMart Quick adapters are local additions.

Only generated scripts and license notices belong in this publication. No session cookies, saved addresses or private workspace files are included.
