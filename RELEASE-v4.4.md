# Swift and Pocket v4.4

All six scouts now use the Swift results layout on desktop and the compact Pocket results layout on mobile. Desktop filters stay in a clear side panel. Mobile uses large tap targets, compact controls and two-column product cards. Selling price, MRP and discount remain visible.

The controls now use simple words: Choose categories, Search level, Find deals fast, Search all selected categories and Search notes. Progress reports searches, pages and products without terms such as aisle or coverage.

The fast search still streams results and stops after 25 seconds. Higher search levels can check more pages. Delivery-address changes invalidate old prices. Results open separately and no cart or order action is performed.

Validation: 55 local tests plus headless visual checks at 1280 px desktop and 390 px Android widths. Both layouts rendered four sample products with no page errors. BigBasket can still return Access Denied on mobile; the scout reports that website refusal plainly.
